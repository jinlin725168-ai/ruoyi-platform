# FEAT-20260923-001

能力：`purchase-order`

## 产品目标

采购单列表和导出的 Excel 都显示供应商分类，列表可以按供应商分类筛选。分类实时取供应商档案上的当前分类，分类为空或已失效时显示『未分类』，这个口径和供应商管理一致。

## 非目标

- 不修改供应商分类字典 biz_supplier_category 及其维护方式，也不修改供应商档案里分类的录入和校验规则
- 不在采购单上保存下单时的供应商分类快照，分类始终取供应商档案上的当前值
- 采购单详情、新增和修改表单不展示或录入供应商分类
- 供应商分类筛选只支持单选，不支持多选
- 不按供应商分类做统计或汇总报表

## 用户故事

- S1 [P1] 采购单分页查询（独立验证：准备分类分别为原材料、服务、空值、已从字典删除的值的供应商，以及一个分类为原材料、已被逻辑删除的供应商，各建一张采购单。只调用采购单列表接口，检查每行的供应商分类显示是否正确；再分别用某个分类和『未分类』筛选，检查返回的单据集合。）
- S7 [P2] 导出采购单 Excel（独立验证：准备分类分别为服务、空值的供应商，各建一张采购单。只调用导出接口，解析返回的 Excel，检查是否有『供应商分类』列、取值是否正确，以及按分类筛选后的数据行。）
