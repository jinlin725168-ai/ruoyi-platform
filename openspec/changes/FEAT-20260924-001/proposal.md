# FEAT-20260924-001

能力：`supplier-management`

## 产品目标

供应商列表和导出新增『编码』查询条件，匹配时和名称条件一样用模糊匹配：编码包含输入内容即命中，去掉首尾空白字符，不区分英文大小写，保留中间空白字符。导出的筛选范围和列表查询保持一致。

## 非目标

- 不改变名称、状态、分类现有的匹配规则
- 新增和修改供应商时，不对录入的编码做去空白或大小写归一化，存储的编码保持原样
- 编码唯一性校验的大小写敏感性不变（本次不把仅大小写不同的编码视为重复）
- 不增加联系人、联系电话等其他查询条件
- 不改变列表和导出的列、分页方式与权限

## 用户故事

- S2 [P1] 分页查询供应商（独立验证：通过列表接口分别查询：用完整编码、编码中间的一段、在编码首尾加各种空白字符、改变编码大小写、只含空白字符的编码作为条件，检查命中结果和总条数；原有名称、状态、分类场景照常通过。）
- S6 [P2] 导出供应商 Excel（独立验证：通过导出接口，分别用编码中间的一段、在首尾加空白并改变大小写后的编码、只含空白字符的编码作为条件请求导出，检查导出文件的行和数据行数，和用同一条件查询列表得到的结果一致；原有导出场景照常通过。）
