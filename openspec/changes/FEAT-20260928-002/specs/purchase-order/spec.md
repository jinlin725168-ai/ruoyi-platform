# purchase-order — delta for FEAT-20260928-002

## ADDED Requirements

### Requirement: 采购单备注录入

_Story S9, priority P1, from FEAT-20260928-002_

As 采购员, 新建采购单或修改草稿采购单时填写、修改或清空备注, so that 我能在单据上记下交期、包装、联系方式等补充说明，并在提交前随时修正.

THE SYSTEM SHALL 在新增采购单时接受选填的备注，保存后原样保留该备注
THE SYSTEM SHALL 允许备注为空：新增或修改时不填写备注不影响保存
WHEN 修改草稿采购单 THE SYSTEM SHALL 以本次提交的备注为准，覆盖原有备注
WHEN 修改草稿采购单时备注被清空 THE SYSTEM SHALL 保存后该单据的备注为空
THE SYSTEM SHALL 按字符数计算备注长度，汉字、英文字母、数字、标点和空白各算 1 个字符，恰好 500 个字符允许保存
WHEN 新增采购单时备注超过 500 个字符 THE SYSTEM SHALL 拒绝保存，返回可读的备注长度提示，并且不产生该采购单
WHEN 修改草稿采购单时备注超过 500 个字符 THE SYSTEM SHALL 拒绝保存，返回可读的备注长度提示，并且单据内容保持不变
WHEN 对已提交的采购单提交带新备注的修改请求 THE SYSTEM SHALL 按『修改草稿采购单』的规则拒绝修改，备注保持不变
THE SYSTEM SHALL 在新增和修改表单中提供备注输入项，输入内容最多 500 个字符

#### Scenario: A98
- **GIVEN** 存在一个启用状态的供应商
- **WHEN** 提交一张带备注『请于月底前送达，外包装需防潮』和一条明细的新增请求
- **THEN** 保存成功，查询该单据详情得到的备注与提交的备注完全一致

#### Scenario: A99
- **GIVEN** 存在一个启用状态的供应商
- **WHEN** 提交一张不带备注、含一条明细的新增请求
- **THEN** 保存成功，查询该单据详情得到的备注为空

#### Scenario: A100
- **GIVEN** 存在一个启用状态的供应商，以及一段由汉字、英文字母和数字混合组成的恰好 500 个字符的备注
- **WHEN** 提交带这段备注的新增请求
- **THEN** 保存成功，查询该单据详情得到的备注与这 500 个字符完全一致

#### Scenario: A101
- **GIVEN** 存在一个启用状态的供应商，以及一段 501 个字符的备注
- **WHEN** 提交带这段备注的新增请求
- **THEN** 保存失败并返回提到备注长度的可读提示，系统中不产生该采购单

#### Scenario: A102
- **GIVEN** 一张备注为 R1 的草稿采购单
- **WHEN** 提交把备注改为 R2 的修改请求
- **THEN** 保存成功，查询该单据详情得到的备注为 R2

#### Scenario: A103
- **GIVEN** 一张备注为 R1 的草稿采购单
- **WHEN** 提交备注为空的修改请求
- **THEN** 保存成功，查询该单据详情得到的备注为空

#### Scenario: A104
- **GIVEN** 一张备注为 R1 的草稿采购单
- **WHEN** 提交备注为 501 个字符的修改请求
- **THEN** 保存失败并返回提到备注长度的可读提示，查询该单据详情得到的备注仍为 R1

#### Scenario: A105
- **GIVEN** 一张备注为 R1 的已提交采购单
- **WHEN** 提交把备注改为 R2 的修改请求
- **THEN** 修改失败并返回已提交不可修改的提示，查询该单据详情得到的备注仍为 R1

#### Scenario: A106
- **GIVEN** 以 admin 登录并打开采购单新增表单
- **WHEN** 选择供应商、填写下单日期、添加一行明细并填写备注后保存
- **THEN** 保存成功，列表中该新单据所在行显示所填的备注


### Requirement: 采购单备注展示

_Story S10, priority P2, from FEAT-20260928-002_

As 采购员或采购主管, 在采购单列表、详情和导出的 Excel 里看到每张单据的备注, so that 我不必进入编辑状态就能了解单据的补充说明，线下汇总和留档时也不会漏掉这些信息.

THE SYSTEM SHALL 在采购单分页列表的每一行返回并显示该单据的备注
THE SYSTEM SHALL 在采购单详情中返回并显示该单据的备注
THE SYSTEM SHALL 在导出的采购单 Excel 中提供列标题为『备注』的列，每行内容与该单据的备注一致
THE SYSTEM SHALL 草稿和已提交的采购单都显示备注
WHEN 采购单备注为空 THE SYSTEM SHALL 在列表、详情和导出 Excel 中把备注显示为空白，不显示占位文字
THE SYSTEM SHALL 在列表中把较长的备注在一行内截断显示，并能查看完整内容

#### Scenario: A107
- **GIVEN** 一张备注为 R 的草稿采购单
- **WHEN** 以该单据的单号查询采购单分页列表
- **THEN** 返回结果中该单据所在行的备注为 R

#### Scenario: A108
- **GIVEN** 一张备注为 R 的已提交采购单
- **WHEN** 按该单据 ID 查询详情
- **THEN** 返回的主表信息中备注为 R

#### Scenario: A109
- **GIVEN** 一张备注为 R 的采购单，当前用户有导出权限
- **WHEN** 以该单据的单号调用导出接口
- **THEN** 导出的 Excel 有列标题为『备注』的列，该单据所在行的备注单元格内容为 R

#### Scenario: A110
- **GIVEN** 一张没有备注的采购单，当前用户有导出权限
- **WHEN** 以该单据的单号调用导出接口
- **THEN** 导出的 Excel 中该单据所在行的备注单元格为空

#### Scenario: A111
- **GIVEN** 以 admin 登录，系统中有一张备注为 R 的采购单
- **WHEN** 进入采购单管理页面，以该单据的单号查询
- **THEN** 表格有『备注』列，该单据所在行显示 R

#### Scenario: A112
- **GIVEN** 以 admin 登录，系统中有一张备注为 R 的采购单
- **WHEN** 在采购单管理页面查看该单据详情
- **THEN** 详情中显示备注 R
