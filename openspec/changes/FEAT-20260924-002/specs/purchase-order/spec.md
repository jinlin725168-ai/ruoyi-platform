# purchase-order — delta for FEAT-20260924-002

## MODIFIED Requirements

### Requirement: 采购单分页查询

_Story S1, priority P1, from FEAT-20260924-002_

As 采购员, 在采购单列表里看到每张单据的供应商分类，并按供应商分类与单号、供应商名称、状态、下单日期组合筛选；按供应商名称搜索时只输入名称的一段也能找到，而且不必在意首尾空白字符和英文大小写, so that 我能按品类或供应商快速定位和跟进采购单，不会因为只记得供应商名称的一段、多敲了空格、粘贴时带入空白字符或大小写不一致而漏掉单据.

THE SYSTEM SHALL 查询条件包括：单号（模糊匹配）、供应商名称（模糊匹配）、状态（草稿/已提交）、下单日期起止范围、供应商分类，可任意组合，未填写的条件不参与过滤
THE SYSTEM SHALL 列表至少展示：单号、供应商名称、供应商分类、下单日期、状态、合计金额、创建时间
THE SYSTEM SHALL 结果分页返回，包含总条数；默认按下单日期倒序、同日期按创建时间倒序
THE SYSTEM SHALL 列表页展示的合计金额与该单据明细金额之和一致
THE SYSTEM SHALL 不做数据权限隔离：任何拥有采购单查询权限的用户都能查询到全部采购单，与单据的创建人和部门无关
THE SYSTEM SHALL 前端页面挂在『业务管理』目录下，路径与菜单配置一致
THE SYSTEM SHALL 采购单的供应商分类取该单据所关联供应商在供应商档案上的当前分类，并显示为供应商分类字典中的名称
WHEN 供应商档案上的分类为空，或分类值已不在供应商分类字典中 THE SYSTEM SHALL 把该采购单的供应商分类显示为『未分类』
WHEN 供应商档案上的分类被修改 THE SYSTEM SHALL 在之后的查询中按修改后的分类显示和筛选该供应商的所有采购单
WHEN 以某个字典中的供应商分类作为条件查询 THE SYSTEM SHALL 只返回所关联供应商当前分类等于该值的采购单
WHEN 以『未分类』作为条件查询 THE SYSTEM SHALL 返回所关联供应商分类为空或已失效的采购单，不返回分类有效的采购单
WHEN 采购单关联的供应商已在档案中被逻辑删除 THE SYSTEM SHALL 仍按该供应商记录上保留的分类显示该采购单的供应商分类（分类为空或已失效时显示『未分类』）
WHEN 采购单关联的供应商已在档案中被逻辑删除 THE SYSTEM SHALL 按该供应商记录上保留的分类让该采购单参与供应商分类筛选
THE SYSTEM SHALL 供应商分类查询条件的可选项来自供应商分类字典，另外提供『未分类』
THE SYSTEM SHALL 对供应商名称条件做模糊匹配：供应商名称包含输入内容即命中
THE SYSTEM SHALL 以采购单上记录的供应商名称（即列表和导出中显示的名称）作为供应商名称条件的匹配对象，不以供应商档案中的当前名称匹配
WHEN 用户以供应商名称作为查询条件 THE SYSTEM SHALL 先去掉该条件首尾的所有空白字符（半角空格、全角空格、制表符、换行等），再参与匹配
THE SYSTEM SHALL 在匹配供应商名称条件时忽略英文字母的大小写差异
THE SYSTEM SHALL 保留供应商名称条件中间的空白字符，按原样参与匹配
WHEN 供应商名称条件去掉首尾空白字符后为空 THE SYSTEM SHALL 视同没有填写供应商名称条件

#### Scenario: A1
- **GIVEN** 系统中已存在若干采购单，其中仅有一张单号包含片段『X9』
- **WHEN** 以单号片段『X9』发起分页查询
- **THEN** 返回结果只包含该单号匹配的单据，总条数为 1

#### Scenario: A2
- **GIVEN** 系统中存在下单日期分别在查询范围内和范围外的采购单
- **WHEN** 以下单日期起止范围发起查询
- **THEN** 返回结果只包含下单日期落在该范围内（含起止当天）的单据

#### Scenario: A3
- **GIVEN** 系统中同时存在草稿与已提交状态的采购单
- **WHEN** 以状态=草稿发起查询
- **THEN** 返回结果中全部单据的状态均为草稿

#### Scenario: A4

### Requirement: 导出采购单 Excel

_Story S7, priority P2, from FEAT-20260924-002_

As 采购主管, 导出的采购单 Excel 带有供应商分类列，导出时也能按供应商分类和供应商名称筛选，供应商名称的匹配规则与列表查询完全一致, so that 导出的范围和我在列表里看到的一致，我能在表格里按供应商或品类做线下汇总与留档.

THE SYSTEM SHALL 导出使用与列表查询相同的过滤条件（含供应商分类和供应商名称），导出的是全部匹配数据而非仅当前页
THE SYSTEM SHALL 导出内容仅为主表数据，一张采购单占一行，包含单号、供应商名称、供应商分类、下单日期、状态、合计金额、备注等主表字段，不包含明细行
THE SYSTEM SHALL 导出需要导出按钮权限，无权限时接口拒绝
THE SYSTEM SHALL 导出文件为 Excel 格式，列标题为中文业务名称，状态显示为中文而非原始码值
THE SYSTEM SHALL 导出的供应商分类列显示字典中的分类名称，取值口径与列表一致（含关联供应商已被逻辑删除的情况）
WHEN 采购单关联供应商的分类为空或已失效 THE SYSTEM SHALL 在导出的供应商分类列中显示『未分类』
WHEN 用户以供应商名称作为导出条件 THE SYSTEM SHALL 采用与列表查询相同的供应商名称匹配规则：以采购单上记录的供应商名称为匹配对象做模糊匹配，去掉首尾所有空白字符（半角空格、全角空格、制表符、换行等），忽略英文字母大小写，保留中间空白字符
WHEN 导出时供应商名称条件去掉首尾空白字符后为空 THE SYSTEM SHALL 视同没有填写供应商名称条件

#### Scenario: A25
- **GIVEN** 系统中存在草稿与已提交的采购单
- **WHEN** 以状态=已提交调用导出接口
- **THEN** 接口返回成功且响应为 Excel 文件内容（非空二进制）

#### Scenario: A26
- **GIVEN** 一个未被授予导出权限的登录用户
- **WHEN** 调用导出接口
- **THEN** 接口返回无权限，不产生任何文件内容

#### Scenario: A27
- **GIVEN** 按查询条件导出得到的 Excel 文件
- **WHEN** 用 Excel 打开该文件
- **THEN** 列标题为中文业务名称并包含『供应商分类』，状态显示为『草稿』或『已提交』，供应商分类显示中文名称或『未分类』，每张采购单占一行且带合计金额，数据行与页面查询结果一致
- _manual acceptance_

#### Scenario: A45
- **GIVEN** 系统中同时存在供应商分类为『服务』和『原材料』的采购单
- **WHEN** 以供应商分类=『服务』调用导出接口
- **THEN** 导出的 Excel 包含『供应商分类』列，所有数据行的该列都是『服务』，行数与同条件列表查询的总条数一致

#### Scenario: A46
- **GIVEN** 一张采购单关联的供应商在档案上的分类为空
- **WHEN** 以该单据的单号调用导出接口
- **THEN** 导出的 Excel 中该单据所在行的供应商分类为『未分类』

#### Scenario: A94
- **GIVEN** 系统中有供应商名称为 N（含大小写混合英文字母）的采购单，以及其他供应商的采购单，用户拥有导出权限
- **WHEN** 以 N 中间一段文字改变大小写、再在前后加半角空格、全角空格或制表符后的内容作为供应商名称条件调用导出接口
- **THEN** 导出文件中每个数据行的供应商名称都包含这段文字（忽略大小写），数据行数等于以同一条件查询列表得到的总条数

#### Scenario: A95
- **GIVEN** 系统中存在多个不同供应商的草稿与已提交采购单，用户拥有导出权限
- **WHEN** 以只由空白字符（半角空格、全角空格、制表符、换行混合）组成的供应商名称条件，并以状态=已提交调用导出接口
- **THEN** 导出文件的数据行数等于只以状态=已提交查询列表得到的总条数
