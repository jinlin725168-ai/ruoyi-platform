# FEAT-20260924-002

能力：`purchase-order`

## 产品目标

采购单列表和导出可以按供应商名称模糊搜索：先去掉输入首尾的空白字符，并且不区分英文大小写；导出使用与列表完全相同的筛选口径，让采购员少输一段、多敲空格或大小写不一致时也不会漏掉单据

## 非目标

- 不新增或调整除供应商名称以外的查询条件（单号、供应商、状态、下单日期、供应商分类的现有行为保持不变）
- 不修改供应商档案本身的查询规则（供应商管理已具备同样的名称匹配规则）
- 不改变列表展示列、排序、分页、导出列和导出格式
- 不支持拼音、繁简转换、同义词或分词等模糊检索
- 不按供应商档案中的当前名称匹配采购单，也不回写或同步采购单上记录的供应商名称

## 用户故事

- S1 [P1] 采购单分页查询（独立验证：通过采购单列表接口，用带首尾空白、改变大小写或只取名称中间一段的供应商名称条件查询，确认结果只包含采购单上记录的供应商名称匹配的单据，并确认只含空白字符的名称条件视同未填写）
- S7 [P2] 导出采购单 Excel（独立验证：用带首尾空白并改变大小写的供应商名称条件调用导出接口，确认导出的数据行数与同条件列表查询的总条数一致，每行供应商名称都匹配；并确认只含空白字符的名称条件视同未填写）
