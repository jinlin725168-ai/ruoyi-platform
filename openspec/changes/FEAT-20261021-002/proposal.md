# FEAT-20261021-002

能力：`frontend-branding`

## 产品目标

把现有 RuoYi 前端统一为“红魔”品牌（全称“红魔业务工作台”，短名“红魔”）：登录页、注册页标题、侧栏展开/折叠标识和浏览器标题都用集中维护的品牌常量；首页的上游推广内容换成对现有供应商管理和采购单管理能力的真实介绍；登录表单初始账号和口令为空。登录、验证码、第三方登录、动态权限菜单、退出等既有行为，以及上游署名和许可证，全部保持不变。

## 非目标

- 不修改 frontend/index.html 与 frontend/.env.*：脚本执行前 HTML 里的静态 <title> 仍取环境变量，它属于底座，不在本次范围；本次只保证应用加载后的浏览器标题
- 不改后端、数据库 schema、业务 SQL、API 签名、构建清单（package.json、vite 配置）、核心依赖和 acceptance/tools 下的受保护验收工具
- 不替换顶栏的上游源码/文档入口，不删除或改写登录页、注册页的上游版权署名和 frontend/LICENSE
- 首页不新增统计接口，不展示编造的业务统计、收益数据或红魔厂商的产品参数和商业背书
- 不为英文等其他语言单独提供品牌译名，品牌名在所有语言下都显示中文“红魔业务工作台”/“红魔”
- 不改变记住账号、验证码、第三方登录、动态菜单和退出登录的现有逻辑

## 用户故事

- S1 [P1] 红魔品牌统一展示（独立验证：用真实浏览器查看登录、注册、侧栏展开/折叠和首页的品牌一致性与标题；格式化纯逻辑由实现阶段单元测试验证，集中维护由独立代码审查确认。）
- S2 [P1] 登录表单不预填口令且既有登录行为保留（独立验证：用冒烟执行器在临时库上打开登录页，确认账号和口令为空；再用已有测试夹具的登录步骤验证正确登录、错误口令、记住账号、第三方入口、验证码关闭和退出登录的行为与改动前一致。）
- S3 [P2] 首页介绍红魔业务工作台的已有能力（独立验证：用冒烟执行器登录后打开首页，核对主标题和能力介绍，并确认上游推广内容和编造的统计/宣传文字都不存在。）
