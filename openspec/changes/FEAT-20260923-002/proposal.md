# FEAT-20260923-002

能力：`supplier-management`

## 产品目标

供应商列表按名称搜索时，忽略输入内容首尾的空白字符（半角空格、全角空格、制表符、换行等），并且英文字母不区分大小写。列表查询和按条件导出都遵守同一规则，业务人员不必记住供应商名称的准确大小写，也不会因为多敲的空格或粘贴时带进来的空白字符而搜不到。

## 非目标

- 不修改已保存的供应商名称，也不在新增或修改供应商时自动去掉名称首尾空白字符
- 不改变状态、分类两个查询条件的匹配方式，也不增加新的查询条件
- 不改变名称条件的模糊匹配方式：名称包含输入内容即命中，不做分词、拼音或错别字容错
- 不改变采购单等其他功能自己的查询条件
- 不改变供应商的新增、修改、删除、权限和分类字典的现有规则

## 用户故事

- S2 [P1] 分页查询供应商（独立验证：通过供应商列表接口单独验证：先准备名称已知、含英文字母的供应商，再用首尾带半角空格、全角空格、制表符或换行，大小写不同，以及只有空白字符的名称条件查询，检查返回的记录和总条数；原有的状态、分类、『未分类』查询场景依然通过。）
- S6 [P2] 导出供应商 Excel（独立验证：通过供应商导出接口单独验证：用首尾带半角空格、全角空格、制表符或换行，大小写不同，以及只有空白字符的名称条件导出，检查导出文件是否包含目标供应商，以及数据行数是否等于按同一条件查询得到的总条数；原有的导出场景依然通过。）

## 澄清记录

### Session FEAT-20260923-002
