# FEAT-20260921-001

能力：`supplier-management`

## 产品目标

让供应商档案带上『供应商分类』（原材料、服务、设备等）。分类值由系统字典维护。新增和修改供应商时必须选择分类，提交的分类不在字典中时拒绝保存。列表显示分类，可以按分类筛选，也可以单独筛出『未分类』的供应商。导出的 Excel 包含分类列。历史数据没有分类，或者所用的分类值已在字典中被删除时，列表和导出都显示『未分类』，按『未分类』筛选或导出时也包含这两类供应商，业务人员可以据此逐步补齐。

## 非目标

- 不支持一个供应商属于多个分类
- 不做多级分类或分类树
- 不提供批量给历史供应商补分类的功能，也不自动迁移历史数据
- 不新增供应商分类专用的维护页面，分类值统一在系统的字典管理中维护
- 不按分类做数据权限隔离
- 不改变采购单等其他业务对供应商的使用方式
- 本期不实现分类的『停用』：系统字典值目前没有启用/停用状态，要等字典支持停用后再做；本期不再使用的分类只能由管理员删除字典值
- 不改变系统字典的删除逻辑，不阻止删除已被供应商使用的分类值

## 用户故事

- S8 [P1] 供应商分类字典（独立验证：系统初始化后，在字典管理中能看到『供应商分类』字典及其三个初始值；管理员新增一个分类值后，新增供应商时能选到它；管理员删除这个分类值后，再用它新增供应商会被拒绝。）
- S3 [P1] 新增供应商（独立验证：调用新增接口：带有效分类时成功；不带分类时失败，并提示分类必填；带字典中不存在的分类值时失败，并提示分类无效。在页面的新增表单中能看到分类可选项，并且分类是必填项。）
- S2 [P1] 分页查询供应商（独立验证：准备不同分类的供应商、一条分类为空的历史供应商，以及一条所用分类值已从字典中删除的供应商。按某个分类查询时只返回该分类的供应商；按『未分类』查询时同时返回分类为空的供应商和分类值已被删除的供应商，不返回分类有效的供应商。在页面上能看到分类列，历史供应商和分类值已被删除的供应商在分类列中都显示『未分类』。）
- S4 [P2] 修改供应商（独立验证：修改一条供应商的分类后，再查询时显示新分类。把分类清空或改成字典中不存在的值后提交，修改会失败。分类为空的历史供应商不选分类就无法保存修改。）
- S6 [P3] 导出供应商 Excel（独立验证：导出的 Excel 表头包含分类列。按某个分类条件导出时，行数等于同条件查询的总条数，且每行的分类都是该分类名称。按『未分类』导出时，文件同时包含分类为空的供应商和分类值已被删除的供应商，行数等于同条件查询的总条数。这两类供应商在导出文件的分类列中都显示『未分类』。）

## 澄清记录

### Session 2026-09-21
- 按分类筛选供应商列表时，是否需要能单独筛出『未分类』（分类为空）的供应商？ → 可以，分类筛选项中包含『未分类』，选中后只显示分类为空的供应商
- 导出 Excel 时，分类为空的历史供应商在分类列中显示什么？ → 显示『未分类』，与列表一致
- 新增或修改供应商时，如果提交的分类值不在『供应商分类』字典中（例如绕过页面直接调用接口），系统如何处理？ → 拒绝保存，并提示分类无效
- 字典中的某个分类被停用后，新增或修改供应商时是否还能选择它？ → 不能选择；已使用该分类的供应商仍正常显示分类名称
- 当前系统的字典值没有『启用/停用』状态，只能新增、修改或删除，因此无法『停用』某个分类。Q4 中『停用后不可选、已有供应商仍显示分类名称』的规则本期如何落实？ → 本期先不实现停用规则，等系统字典支持停用后再做；本期不再使用的分类只能靠管理员删除字典值
- 管理员在字典管理中删除了一个已被供应商使用的分类值后，这些供应商在列表和导出中的分类显示什么？ → 显示『未分类』，与分类为空的供应商同等处理
- 分类值被删除后，相关供应商会显示『未分类』。按『未分类』筛选列表或导出时，是否也要包含这些供应商（它们保存的分类值还在，只是字典里已经没有了）？ → 包含：分类为空的供应商和分类值已不在字典中的供应商，都能用『未分类』筛出来
