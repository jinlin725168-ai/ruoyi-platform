# Decisions for FEAT-20260921-001

## Idea

供应商管理增强：给供应商档案增加『供应商分类』字段，分类值由系统字典维护（初始值：原材料、服务、设备），新增和修改表单必须选择分类，列表显示分类并支持按分类筛选，导出 Excel 包含分类列。已有的供应商数据分类为空时列表显示为『未分类』。
