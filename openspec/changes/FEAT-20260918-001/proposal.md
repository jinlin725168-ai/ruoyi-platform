# FEAT-20260918-001

## 产品目标

在『业务管理』目录下提供供应商管理功能。有权限的用户可以维护供应商档案，包括供应商编码、名称、联系人、联系电话、启用/停用状态和备注。用户可以按名称和状态分页查询，也可以新增、修改、删除供应商并导出 Excel。列表、新增、修改、删除、导出分别受按钮级权限控制。后端接口和前端页面都要交付。

## 非目标

- 不包括供应商资质、证照、银行账户、地址等档案之外的扩展信息
- 不包括采购订单、询价、对账、结算等与供应商有关的交易业务
- 不包括 Excel 批量导入供应商
- 不包括供应商评级、考核或黑名单管理
- 不包括供应商自助门户或供应商登录
- 不包括供应商新增、修改的审批流程
- 不改动 RuoYi 底座已有的系统管理功能和权限模型
- 不提供列表中的启用/停用快捷开关
- 不按部门对供应商数据做数据权限隔离
