# supplier-management Specification

## Purpose
Behavior of the supplier-management capability, accumulated from StoryLoop changes.

## Requirements

### Requirement: 『业务管理』目录与供应商管理菜单

_Story S1, from FEAT-20260918-001_

As 系统管理员, 在系统菜单中看到一个新的『业务管理』目录，其下有『供应商管理』菜单和对应的按钮权限, so that 我可以通过角色把供应商管理的访问权和各项操作权分配给不同用户.

The system SHALL 『业务管理』是一个新的顶级目录
The system SHALL 『供应商管理』菜单挂在『业务管理』目录下
The system SHALL 供应商管理有五个独立的按钮级权限：列表（查询）、新增、修改、删除、导出
The system SHALL 没有供应商管理菜单权限的用户在导航中看不到该菜单（本期不验收）

#### Scenario: A1
- **GIVEN** 系统已完成初始化，管理员 admin 已登录
- **WHEN** 管理员查看菜单管理列表
- **THEN** 列表中有顶级目录『业务管理』，其下有菜单『供应商管理』，该菜单下有查询、新增、修改、删除、导出五个按钮权限

#### Scenario: A2
- **GIVEN** 管理员 admin 已登录前端
- **WHEN** 管理员展开左侧导航的『业务管理』
- **THEN** 导航中出现『供应商管理』，点击后打开供应商列表页面

### Requirement: 分页查询供应商

_Story S2, priority P1, from FEAT-20260924-001_

As 有供应商列表权限的业务人员, 按供应商编码、名称、状态和分类分页查询供应商列表，并看到每个供应商的分类；按编码或名称搜索时只输入其中一段也能找到，而且不必在意首尾空白字符和英文大小写, so that 我能快速找到某个或某一类供应商，也能筛出还没有有效分类的供应商逐步补齐，不会因为只记得编码的一段、多敲了空格、粘贴时带进来空白字符或大小写不一致而漏掉供应商.

THE SYSTEM SHALL 在列表中显示供应商编码、名称、分类、联系人、联系电话、状态、备注
THE SYSTEM SHALL 在列表中把分类显示为字典中的分类名称
WHEN 供应商的分类为空 THE SYSTEM SHALL 在列表的分类列中显示『未分类』
WHEN 供应商的分类值已不在『供应商分类』字典中 THE SYSTEM SHALL 在列表的分类列中显示『未分类』
THE SYSTEM SHALL 只提供编码、名称、状态和分类四个查询条件，条件可以组合，也可以都不填
WHEN 用户同时填写多个查询条件 THE SYSTEM SHALL 只返回同时满足全部条件的供应商
THE SYSTEM SHALL 对名称条件做模糊匹配：供应商名称包含输入内容即命中
WHEN 用户以名称作为查询条件 THE SYSTEM SHALL 先去掉名称条件首尾的所有空白字符（半角空格、全角空格、制表符、换行等），再参与匹配
THE SYSTEM SHALL 在匹配名称条件时忽略英文字母的大小写差异
THE SYSTEM SHALL 保留名称条件中间的空白字符，按原样参与匹配
WHEN 名称条件去掉首尾空白字符后为空 THE SYSTEM SHALL 视同没有填写名称条件
THE SYSTEM SHALL 对编码条件做模糊匹配：供应商编码包含输入内容即命中，与名称条件相同
WHEN 用户以编码作为查询条件 THE SYSTEM SHALL 先去掉编码条件首尾的所有空白字符（半角空格、全角空格、制表符、换行等），再参与匹配
THE SYSTEM SHALL 在匹配编码条件时忽略英文字母的大小写差异
THE SYSTEM SHALL 保留编码条件中间的空白字符，按原样参与匹配
WHEN 编码条件去掉首尾空白字符后为空 THE SYSTEM SHALL 视同没有填写编码条件
THE SYSTEM SHALL 在供应商管理页面的查询区提供编码查询条件
THE SYSTEM SHALL 在分类查询条件的可选项中提供『供应商分类』字典中的分类以及『未分类』
WHEN 用户以某个分类作为条件查询 THE SYSTEM SHALL 只返回属于该分类的供应商
WHEN 用户以『未分类』作为分类条件查询 THE SYSTEM SHALL 返回分类为空的供应商
WHEN 用户以『未分类』作为分类条件查询 THE SYSTEM SHALL 同时返回分类值已不在『供应商分类』字典中的供应商
WHEN 用户以『未分类』作为分类条件查询 THE SYSTEM SHALL 不返回分类值仍在『供应商分类』字典中的供应商
THE SYSTEM SHALL 让状态沿用系统字典 sys_normal_disable，只有 0=正常（启用）和 1=停用两种
THE SYSTEM SHALL 分页显示查询结果，并展示总条数
THE SYSTEM SHALL 不在列表中显示已删除的供应商
WHEN 没有列表权限的用户调用查询接口 THE SYSTEM SHALL 拒绝该请求

### Requirement: 新增供应商

_Story S3, priority P1, from FEAT-20260921-001_

As 有供应商新增权限的业务人员, 录入一个新的供应商档案，并为它选择分类, so that 系统里有这个供应商的基础信息和所属分类，后续业务可以使用.

THE SYSTEM SHALL 在新增时录入供应商编码、名称、分类、联系人、联系电话、状态、备注
THE SYSTEM SHALL 要求供应商编码由用户手工录入且必填，在未删除的供应商中唯一；已删除供应商的编码可以被新供应商再次使用
THE SYSTEM SHALL 要求供应商名称必填，不要求唯一
THE SYSTEM SHALL 要求新增时必须选择分类
THE SYSTEM SHALL 只从『供应商分类』字典中提供分类可选项
WHEN 提交的分类值不在『供应商分类』字典中 THE SYSTEM SHALL 拒绝保存，并提示分类无效
THE SYSTEM SHALL 把联系人和联系电话作为选填项，不校验联系电话格式
THE SYSTEM SHALL 在新增时默认状态为启用（0=正常）
WHEN 没有新增权限的用户调用新增接口 THE SYSTEM SHALL 拒绝该请求（页面不显示新增按钮本期不验收）

- **THEN** 返回成功，之后按该名称查询能查到这条新供应商，各字段（包括分类）与提交的一致

### Requirement: 导出供应商 Excel

_Story S6, priority P2, from FEAT-20260924-001_

As 有供应商导出权限的业务人员, 把供应商数据（包括分类）导出为 Excel 文件；按编码或名称筛选导出时，和列表一样用模糊匹配，并且忽略首尾空白字符和英文大小写, so that 导出的范围和我在列表里看到的一致，可以离线按分类查看、归档，或提供给其他部门使用.

THE SYSTEM SHALL 以 Excel 格式导出文件
THE SYSTEM SHALL 在导出列中包括供应商编码、名称、分类、联系人、联系电话、状态、备注
THE SYSTEM SHALL 在导出文件中把分类显示为字典中的分类名称，而不是字典值代码
WHEN 供应商的分类为空 THE SYSTEM SHALL 在导出文件的分类列中显示『未分类』
WHEN 供应商的分类值已不在『供应商分类』字典中 THE SYSTEM SHALL 在导出文件的分类列中显示『未分类』
THE SYSTEM SHALL 在导出文件中按字典 sys_normal_disable 把状态显示为可读文字（正常/停用），而不是 0/1
THE SYSTEM SHALL 不分页导出符合当前查询条件（编码、名称、状态、分类）的全部数据，筛选范围与列表查询一致
WHEN 用户以名称作为导出条件 THE SYSTEM SHALL 采用与列表查询相同的名称匹配规则：模糊匹配，去掉首尾所有空白字符（半角空格、全角空格、制表符、换行等）、忽略英文字母大小写、保留中间空白字符
WHEN 导出时名称条件去掉首尾空白字符后为空 THE SYSTEM SHALL 视同没有填写名称条件
WHEN 用户以编码作为导出条件 THE SYSTEM SHALL 采用与列表查询相同的编码匹配规则：模糊匹配（编码包含输入内容即命中），去掉首尾所有空白字符（半角空格、全角空格、制表符、换行等）、忽略英文字母大小写、保留中间空白字符
WHEN 导出时编码条件去掉首尾空白字符后为空 THE SYSTEM SHALL 视同没有填写编码条件
WHEN 用户以『未分类』作为分类条件导出 THE SYSTEM SHALL 导出分类为空的供应商和分类值已不在『供应商分类』字典中的供应商，不导出分类值仍在字典中的供应商
