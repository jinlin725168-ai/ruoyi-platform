# RuoYi 供应商管理测试计划

## Application Overview

被测应用：RuoYi-Vue-Plus 后台（http://127.0.0.1:35289）。登录页 /login，账号 admin / admin123。页面上仍有验证码输入框，但后端已关闭验证码，直接点击「登 录」即可进入 /index。

本次变更在顶部菜单『业务管理』下新增「供应商管理」（路由 /biz/supplier）。页面结构（已实测）：
- 面包屑：首页 / 业务管理 / 供应商管理
- 「筛选条件」区：供应商名称输入框（占位符「请输入供应商名称」）、状态下拉（占位符「供应商状态」）、「搜索」「重置」按钮
- 「供应商列表」区：标题下显示「共 N 条记录，支持供应商档案维护和导出。」；工具栏有「新增」「修改」「删除」「导出」和一个列设置图标按钮。未选中行时「修改」「删除」不可用
- 表格列：勾选框、供应商编码、供应商名称、联系人、联系电话、状态（正常/停用）、备注、操作。操作列有两个纯图标按钮（第 1 个为修改，第 2 个为删除），没有可访问名称
- 分页：共 N 条、每页条数下拉（默认 10条/页）、上一页/下一页、页码、「前往 _ 页」
- 新增弹窗标题「添加供应商」，修改弹窗标题「修改供应商」。字段：* 供应商编码、* 供应商名称、联系人、联系电话、状态单选（正常[默认]/停用）、备注（多行）；按钮「确 定」「取 消」及右上角关闭按钮
- 已确认的行为：必填项为空时提示「供应商编码不能为空」「供应商名称不能为空」；编码重复时提示「新增供应商'XXX'失败，供应商编码已存在」，弹窗不关闭；保存成功提示「操作成功」；修改时供应商编码框不可编辑

数据约定：每个场景都从全新状态开始，自己准备数据。编码和名称统一加上唯一后缀（如 AUTO_<时间戳>），场景结束后尽量删除自己创建的数据，避免场景之间互相影响。

探索中发现的问题：联系电话填「abc」也能保存成功，前后端都没有校验格式。需求没有明确要求格式校验，请产品确认；本计划把它列为待确认的检查项。
